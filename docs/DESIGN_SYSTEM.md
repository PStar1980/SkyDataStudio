# Aurora Foundry Design System

SkyData Studio preserves the structural language of SkyCommand while establishing its own data-engineering identity.

## Palette

| Token | Value | Use |
|---|---:|---|
| Ink | `#050b12` | Deep application background |
| Surface | `#0b1620` | Cards and panels |
| Raised | `#102331` | Interactive or elevated surfaces |
| Teal | `#42d9c6` | Healthy data movement and primary actions |
| Mint | `#8bf5dc` | Highlights and trusted outcomes |
| Violet | `#9a83ff` | Models, transformations, and lineage |
| Amber | `#f3bd55` | Warnings, review states, quality attention |
| Coral | `#ff6f82` | Failures and blocked publication |
| Text | `#edf8f6` | Primary copy |
| Muted | `#91aeb2` | Secondary copy |

## UX conventions

- Operational tables remain the authoritative detail surface.
- Visual summaries explain trends, concentration, and health above tables.
- Status colours carry the same meaning across dashboards, runs, quality, and lineage.
- Destructive and publishing actions require deliberate confirmation.
- Complex metadata opens in overlays rather than permanently narrowing the workbench.
- Accordion groups preserve context and reduce navigation sprawl.
