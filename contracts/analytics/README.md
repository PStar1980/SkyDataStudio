# Analytics consumer contracts

This directory holds source-controlled declarations for downstream analytics consumers.

Phase 8.5 uses these declarations only for lineage and impact analysis. A declaration says which governed semantic model, metrics, and dimensions a consumer requires. It does **not** claim that a Power BI workspace, semantic model, report, refresh schedule, or deployment has already been provisioned.

Actual analytical delivery and Power BI service integration remain Phase 9 and Phase 10 responsibilities.
